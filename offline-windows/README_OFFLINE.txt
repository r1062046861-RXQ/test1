五行医道 - Windows 离线版

使用方法：
1. 把整个 offline-windows 文件夹复制到 Windows 11 电脑上。
2. 双击 open-game.cmd。
3. 游玩时不要关闭弹出的黑色服务器窗口。
4. 停止游戏时，关闭这个窗口，或在窗口里按 Ctrl+C。

运行要求：
- Windows 11 自带 PowerShell 即可。
- 不需要 Node.js、npm、Python、网络连接或安装步骤。

如果浏览器没有自动打开：
- 复制黑色窗口里显示的网址，通常是 http://127.0.0.1:5173/
- 粘贴到 Edge 或 Chrome 打开。

注意：
- 不要删除或重命名 web 文件夹，里面是游戏文件。

Five Elements Medical Way - Windows Offline Package

How to use:
1. Copy this whole offline-windows folder to the Windows 11 computer.
2. Double-click open-game.cmd.
3. Keep the black PowerShell/server window open while playing.
4. To stop the game, close that window or press Ctrl+C.

Requirements:
- Windows 11 with PowerShell, which is included by default.
- No Node.js, npm, Python, internet connection, or installation step is required.
